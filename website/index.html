    Pin NotchPrompter from Chrome's puzzle-piece menu. Open a normal website, click the extension, paste your script, then choose Show on this tab.

Inside Chrome: the overlay stays in the web page. It cannot float over desktop apps, Chrome settings, the Web Store, or some built-in viewers. Invoke it again after reloading or navigating.

Recording: the Chrome overlay is visible when its tab or display is recorded/shared. It does not monitor your camera. Alt + Shift + Y shows it, Alt + Shift + P plays/pauses, and Alt + Shift + R restarts. On Mac, Alt is Option. Remap conflicts at chrome://extensions/shortcuts.

Scripts save in browser-local storage. Access is temporary and limited to the tab where you invoke it. The script becomes part of that page's display, so use pages you trust. This is a developer-mode download, not a Chrome Web Store listing. Managed work/school browsers may restrict it.

Native Mac beta

About the Apple warning.

The native Mac app is ad-hoc signed, but it has no Apple Developer ID or notarization ticket. macOS may block a downloaded copy with an unidentified-developer or “Apple cannot check for malicious software” warning. The .app format by itself does not establish trust.

Use the Chrome extension above for the browser workflow, or build the native app locally with Apple's free Command Line Tools. A locally built copy has a different trust history; your Mac's security policies still apply. If you trust the downloaded beta, Apple explains the per-app approval options. If the warning says the app will damage your computer, stop and investigate that copy; it is a different warning.

Native desktop setup

Three steps to your first take.

  1. 1

    Download and open it

    On Windows, run NotchPrompter.exe. On Mac, unzip the download and drag NotchPrompter.app to Applications. Open the tray or menu bar icon for settings.

  2. 2

    Paste your script

    Press Ctrl Alt E on Windows, or Control Option E on Mac, and paste. Wrap words in *asterisks* to highlight them; use # for a section label.

  3. 3

    Hit record and press play

    Open the island and press Ctrl Alt Space (Mac: Control + Option + Space) for a 3-2-1 countdown. Check your recording setup, then read with your eyes on the lens.

FAQ

Questions, answered.

Does it really not show up in recordings?

On Windows, NotchPrompter requests WDA_EXCLUDEFROMCAPTURE so compatible capture tools can omit it. Test your recorder and sharing setup. On Mac, capture exclusion is not guaranteed; the overlay may appear in display recordings and screen sharing. Share a particular app window or record webcam-only. Neither app can hide from a camera pointed at your screen.

Windows says "Windows protected your PC". Is that normal?

Yes, for now. The app isn't code-signed yet, so Microsoft SmartScreen warns about new downloads. Click More info, then Run anyway. Your browser may also ask you to confirm the download. You can compare the file's checksum below with the one on this page.

Which versions of Windows does it support?

Windows 10 (version 2004 or newer) and Windows 11. It runs on .NET Framework 4.8, which those versions already include, so there's nothing else to install. On older Windows 10 builds it still works, but recordings show a black box instead of hiding it completely.

Is there a Mac version?

There are two Mac options: the Chrome extension, which runs inside a web page, and a native Mac beta for macOS 13+, Apple Silicon and Intel. The native beta is unnotarized, so macOS may block installation. See the Mac installation options. Native Mac capture exclusion is not guaranteed; the Chrome overlay appears in tab recordings.

Where is my script saved?

Windows: %APPDATA%\NotchPrompter\script.txt. Native Mac: ~/Library/Application Support/NotchPrompter/script.txt. Chrome extension: browser-local storage for this Chrome profile. Nothing is uploaded or synced. Keep a separate copy before removing the extension, because uninstalling it removes its stored script.

How do I stop it starting with Windows, or remove it?

Right-click the tray icon and untick Start with Windows, then choose Quit. To remove it completely, delete NotchPrompter.exe and the %APPDATA%\NotchPrompter folder.
